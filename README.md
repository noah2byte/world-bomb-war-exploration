# World Bomb War — Exploration

`world-bomb-war-game`과 같은 세계관(World Bomb War Universe)을 공유하는
별개의 게임. 플레이어가 세계를 돌아다니며 핵전쟁으로 무너지는 세계를
직접 경험하는 탐험 게임을 목표로 한다.

현재는 MVP 1단계 — WorldState/WorldEvent/News 파이프라인 검증용 디버그
화면만 있다.

## 실행

```bash
npm install
npm run dev
```

## 개발 가이드

Claude Code로 작업을 이어갈 계획이라면 [`CLAUDE.md`](./CLAUDE.md)를 먼저
읽을 것 — 세계관, 코드 원칙, 현재 진행 상태, 다음 할 일 순서가 정리되어
있다.
