# npc/

WorldState를 반영하는 NPC 대사 시스템 (마스터 프롬프트 11번 섹션).

## 아직 미구현 — MVP 이후 단계에서 착수

설계 방향만 미리 적어둔다:

- `dialogue.js` — `(npcId, worldState) => string` 형태의 순수 함수로
  시작한다. 조건 분기(if/switch)로 시작해도 되지만, NPC와 대사 후보가
  늘어나면 조건 테이블(데이터 기반)로 옮긴다.
- 향후 LLM 기반 NPC를 붙일 때를 대비해, "대사를 결정하는 함수"와
  "대사를 화면에 그리는 컴포넌트"를 반드시 분리해서 구현할 것 —
  나중에 결정 로직만 LLM 호출로 교체 가능해야 한다.
